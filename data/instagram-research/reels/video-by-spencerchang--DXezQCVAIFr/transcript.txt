I made a tool to make any website feel alive. Let me show you. This is PlayHTML. It's an open-source library that lets you turn any website into a live shared space. Everything you do happens in real time for everyone else. And when you leave, your traces stay for others to find. People have already made all kinds of amazing web spaces, from games to personal website stoops. I've dreamed of making building with PlayHTML feel as fun and communal as these spaces. But right now, the docs are just markdown files on GitHub. As a solo maintainer, I've never had time to change that. So I used Cursor to research the right frameworks and build the foundation for this interactive docs website, which meant I could spend my time designing the thing that matters most: making it feel like a live playground. Every example is live for you to interact with, and you can see the traces of other people copying snippets in real time. Now, learning PlayHTML feels as fun as the spaces that you can make with it. Check it out, and let's make more whimsical internet spaces.
